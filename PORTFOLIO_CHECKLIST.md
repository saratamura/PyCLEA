# Before making this repository public

- [ ] Run `python PyCLEA.py` on your computer and test the complete observation workflow.
- [ ] Check your research advisor/program's publication requirements.
- [ ] Confirm the galaxy data source license and attribution, including for the 30,000-row sample.
- [ ] Confirm permission to redistribute the telescope audio.
- [ ] Add screenshots from your actual application.
- [ ] Add your advisor and collaborators to acknowledgments.
- [ ] Consider adding the lab manual/poster only if you have permission.
- [ ] Ensure no private data, passwords, or institution-only files are included.
- [ ] Choose an appropriate code license after confirming ownership.
